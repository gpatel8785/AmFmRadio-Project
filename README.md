**Usage:**

Once the program is running, follow the on-screen instructions to interact with the radio. You can toggle the power, adjust volume, switch between AM and FM bands, set and select preset buttons, scan frequencies, and display current settings.

**Features:**

**Power Toggle**: Turn the radio on or off.
**Volume Control:** Set the volume level (0-100).
**Band Toggle:** Switch between AM and FM bands.
**Preset Buttons:** Set and select preset buttons for quick tuning.
**Frequency Scanning:** Scan frequencies up or down.
**Display Settings:** View current radio settings.
